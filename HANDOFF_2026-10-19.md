## What's new since Oct 8

### App shell
- **Routes:** `*` is now `NotFoundPage` (`src/pages/NotFoundPage.jsx`), no longer a redirect to `/planner`. Routes: `/`, `/login`, `/planner`, `/scheduler`.
- **Update banner** (`UpdateBanner.jsx`): `vite.config.js` bakes a build id (`VITE_BUILD_ID` = short git hash, or `BUILD_ID` env, else timestamp) and emits `dist/version.json`. The banner polls `/version.json` every 5 min and on focus/visibility, dismissal lasts 30 min, off in dev. "Save and reload" calls `flushAllPendingWrites` (`utils/pendingWrites.js`) and reloads only if every flush succeeded. Planner (plan and profile) and Scheduler draft register flushers. `firebase.json` serves `/version.json` with `no-cache`. This touches the autosave flush area; changes there need care.
- **Beta modal removed.** `terrierplan_beta_seen` is no longer written; it is only *read* by `utils/firstTimer.js` to detect returning users.
- **First-visit card** (`PickYourPath.jsx`, shown by `PlannerPage` on an empty plan): Import my transcript / Import a plan / Start from scratch / Skip. Sets `terrierplan_onboarded_v2`. First-timers get the right panel collapsed and one-time hints; returning users skip both.
- **One-time hints** (`OneTimeHint.jsx`, `hooks/useOneTimeHint.js`, `utils/hintQueue.js`): a global queue so only one hint shows at a time (1.5 s gap). Used for hub, credits, hub finder/potential, current semester, lock, plans, scheduler sections, transfer credit.
- New small pieces: `Toast.jsx` (with Undo), `PawLoader.jsx`, `Disclaimer.jsx`, `EstimateNote.jsx`, `FullViewHeader.jsx`, `HeaderMenu.jsx` (planner toolbar dropdowns), `PanelResizeHandle.jsx` + `hooks/useResizableWidth.js` (resizable side panels), `hooks/useDesktopLayout.js`, `useDelayedBusy.js`.
- **Art credit:** `constants/credits.js` credits Liberty Miller for the terrier mascot (`public/terrier_7.png`); paw logo and Rhett art credited to BUowo. Footer shows it.
- `index.html` has two new lines (not inspected).

### Plan PDF export and import
- **Download** (`utils/planPdf.js`, `planPdfModel.js`): landscape letter PDF drawn with `pdf-lib` (new dep, pinned `1.17.1`), auto-shrinks to fit one page, embeds `terrierplan-plan.json` (format `terrierplan-plan`, version 1) as an attachment. Loaded via dynamic import on click.
- **Import** (`utils/planImport.js`): reads the attachment back with pdfjs and sanitizes it (whitelist, size caps: 8 MB file, 256 KB blob, 16 slots, etc.). Wired into `ImportTranscriptModal.jsx` and `PlannerPage.jsx` ("Import plan PDF" in the Import menu). The header comment in `planPdf.js` ("nothing reads the attachment back yet") is stale.
- Not tested against a real exported file in a browser: **unverified**.
